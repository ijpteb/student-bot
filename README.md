# Учебный бот для студентов

Telegram-бот: расписание, домашние задания и напоминания о них.
**Бот неофициальный и не связан ни с одним вузом.**

Сейчас готов **этап 2 — ручной режим**: студент сам вносит предметы и расписание
(с чётными/нечётными неделями, разовыми парами и отменами), записывает домашние задания
с фото и файлами и получает напоминания. Подключение к системам вузов — следующие этапы.

## Запуск на Mac с нуля

Понадобится около 20 минут. Всё бесплатно.

### Шаг 1. Создать бота в Telegram (получить токен)

1. Откройте Telegram и найдите **@BotFather** (у настоящего синяя галочка).
2. Нажмите **Start** (или отправьте `/start`).
3. Отправьте `/newbot`.
4. BotFather спросит **имя** бота — это то, что видят люди. Например: `Учебный помощник`.
5. Затем спросит **username** — адрес бота, латиницей, обязательно на `bot` в конце.
   Например: `my_study_helper_bot`. Если занято — придумайте другой.
6. BotFather пришлёт сообщение с **токеном** — строка вида `1234567890:AAH...`.
   Это пароль от бота: **никому его не показывайте** и не публикуйте.
   Пока просто оставьте это сообщение открытым — токен понадобится в шаге 4.

### Шаг 2. Установить Docker Desktop

Docker — программа, которая запускает бота и базу данных одной командой.
Для личного использования она бесплатна.

1. Узнайте, какой у вас процессор: меню  → **Об этом Mac**. Если написано
   «Чип Apple M1/M2/M3/M4…» — у вас **Apple chip**, если «Процессор Intel» — **Intel**.
2. Откройте https://www.docker.com/products/docker-desktop/ и скачайте версию
   для Mac с вашим процессором.
3. Откройте скачанный файл `Docker.dmg` и перетащите **Docker** в папку **Программы**.
4. Запустите **Docker** из папки «Программы». Согласитесь с условиями.
   Регистрироваться не обязательно — можно нажать **Skip** / «Пропустить».
5. Дождитесь, пока значок кита в строке меню вверху экрана перестанет «шевелиться».

### Шаг 3. Скачать код бота

1. Откройте программу **Терминал** (Программы → Утилиты → Терминал).
2. Вставьте эту команду и нажмите Enter:

   ```bash
   cd ~/Documents && git clone https://github.com/ijpteb/student-bot.git
   ```

   Если Mac предложит установить «инструменты разработчика командной строки» —
   нажмите **Установить**, дождитесь конца и выполните команду ещё раз.
3. В папке **Документы** появится папка **student-bot**. Терминал можно закрыть.

> Обновления потом скачиваются сами при каждом запуске бота (шаг 4).

### Шаг 4. Первый запуск

1. Откройте папку **Документы → student-bot** в Finder.
2. Дважды щёлкните файл **«Запустить бота.command»**.
   - Если macOS пишет, что не может проверить разработчика: откройте
     **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите
     **«Всё равно открыть»**. В старых версиях macOS: правый щелчок по файлу → **Открыть**.
     Это нужно один раз.
3. Откроется файл настроек `.env` в TextEdit. В строке `BOT_TOKEN=` вставьте токен
   из шага 1 **сразу после знака `=`**, без пробелов и кавычек. Должно получиться так:
   `BOT_TOKEN=1234567890:AAH...`
4. Сохраните файл (**Cmd+S**) и закройте TextEdit.
5. Снова дважды щёлкните **«Запустить бота.command»**. Первый раз сборка займёт
   несколько минут. Скрипт сам проверит, что бот подключился к Telegram, и напишет
   **«✅ Бот запущен»**. Если что-то не так, он напишет **«❌ Бот не запустился»**, покажет причину
   и подскажет, что исправить.

### Шаг 5. Стать владельцем бота

Владелец получает сообщения об ошибках и служебную команду `/stats`.

1. Найдите своего бота в Telegram по username из шага 1 и нажмите **Start**.
2. Отправьте боту `/id` — он ответит числом, это ваш Telegram ID.
3. Откройте файл настроек: в программе **Терминал** выполните команду

   ```bash
   open -e ~/Documents/student-bot/.env
   ```

4. В строке `ADMIN_ID=` впишите это число сразу после `=`, сохраните (**Cmd+S**) и закройте.
5. Ещё раз запустите **«Запустить бота.command»** — бот пришлёт вам «✅ Бот запущен».

### Как остановить

Дважды щёлкните **«Остановить бота.command»**. Все данные сохранятся.

> Пока бот запущен на вашем Mac, он работает, только когда Mac включён и не спит.
> Круглосуточная работа на сервере — этап 6.

## Как проверить этап 2 в Telegram

1. `/start` → напишите название вуза (или «Пропустить»). Бот покажет, по какому часовому
   поясу считает время (по умолчанию — Москва), и предложит сменить его.
2. **⚙️ Настройки → ✏️ Расписание → ➕ Добавить пару**: предмет, день недели,
   время `9:00-10:30`, «Каждую неделю», детали `305, Иванова А.П., лекция`.
   Добавьте ещё пару только по **нечётным** неделям.
3. **📅 Сегодня / 📅 Завтра / 🗓 Неделя / ⏭ Ближайшая пара** — пары на месте,
   в заголовке видно номер и чётность недели. Листайте кнопками ◀️ ▶️ — пара
   «по нечётным» появляется через неделю.
4. Под расписанием дня: **✏️ Изменения на этот день** → отмените пару (она пропадёт
   только в этот день) и добавьте разовую пару.
5. **➕ Задание**: предмет → текст (можно с фото) → срок «К следующей паре» →
   напоминание: напишите время на 2–3 минуты вперёд, например `14:05`.
   В указанное время придёт **⏰ Напоминание** с кнопкой **✅ Выполнено**.
6. Проверка «не теряется при перезапуске»: добавьте **новое** задание (не отмеченное
   выполненным) с напоминанием через 5 минут, остановите бота, подождите, пока время
   пройдёт, и запустите снова — напоминание придёт сразу после запуска.
   О выполненных заданиях бот не напоминает.
7. **⚙️ Настройки → 🕗 Сводка** — поставьте время на 1–2 минуты вперёд:
   придёт список невыполненных заданий. Отметьте все выполненными — на следующий
   день сводка не придёт.
8. **⚙️ Настройки → 🌍 Часовой пояс** — смените на Екатеринбург: напоминания
   будут срабатывать по екатеринбургскому времени.
9. Попросите знакомого написать боту: он не увидит ваших предметов и заданий.
10. `/stats` (только от вашего аккаунта) — статистика и заявки на подключение вузов.
11. **⚙️ Настройки → 🗑 Удалить все мои данные** — всё удаляется.

## Если что-то не так

| Что видите | Что сделать |
|---|---|
| «Не найден Docker» | Установите Docker Desktop (шаг 2) и запустите его |
| «Docker не запустился» | Откройте Docker Desktop вручную, дождитесь, пока кит перестанет шевелиться |
| «❌ Бот не запустился» | Прочитайте причину в окне. Чаще всего это токен или опечатка в `.env`. Если непонятно — пришлите текст окна Claude (токена в нём нет) |
| «Telegram не принял токен (Unauthorized)» | Неверный токен: проверьте строку `BOT_TOKEN=` в `.env` |
| «Ошибка в файле .env — проверьте строки: …» | Исправьте названные строки в `.env` |
| «Нет связи с сервером Telegram» | Проверьте интернет. Если Telegram недоступен из вашей сети — напишите Claude, настроим `TELEGRAM_PROXY` |
| Бот не отвечает | Запустите «Запустить бота.command» ещё раз: он покажет, что не так |
| Открыть файл `.env` | В Терминале: `open -e ~/Documents/student-bot/.env` (в Finder он скрыт — **Cmd+Shift+.** показывает скрытые файлы) |

Полностью удалить бота вместе с базой данных (необратимо): в Терминале в папке проекта

```bash
docker compose down -v
```
